## GitHub Pages setup

The public `arrow-legal` repository publishes from the `main` branch root. Product pages are linked from `index.html` and share the repository's GitHub Pages domain.

For a future product, add one product directory and link its privacy, support, and terms pages from `index.html`.

For support or privacy questions, contact `leo0912v@gmail.com`.

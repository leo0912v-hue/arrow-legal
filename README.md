# Arrow Legal Pages

Static GitHub Pages site for product privacy policies, support pages, and terms of use.

## Current product

- `meowline-arrow-escape/privacy-policy.html`
- `meowline-arrow-escape/support.html`
- `meowline-arrow-escape/terms-of-use.html`

## GitHub Pages setup

1. Upload the contents of this folder to the public `arrow-legal` repository.
2. Commit them to the `main` branch.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then **Save**.
5. Confirm that the home page and the three product pages open in a private browser window before entering the URLs in App Store Connect.

For a future product, add one new product directory and link its pages from `index.html`.
